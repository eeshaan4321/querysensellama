NOTES
-----
- Prompt check: for 5 of the 5 queries the backend sent to the LLM, its SQL matched a Case 1
  call for the same question word for word, so both cases sent the same prompt. Case 2 token
  counts are taken from that matching call.
- A warm-up call was made before each case and is not counted, so neither case pays the
  one-off cost of loading the model into GPU memory.
- Case 1 has no cache: a system that sends everything to the LLM calls it again for a
  repeated question. Queries 16-20 repeat 11-15 to show what the cache saves in Case 2.
- Input tokens are fixed by the prompt. Output tokens can vary slightly between calls even at
  temperature 0, because the model sometimes words the same answer differently.
  In this run: "Show rentals from last month": 20 and 41 output tokens (first call and repeat in Case 1).
- Times are from one run on this machine and vary between runs.
